JUSTIN ALLENJA 库存手机安装

JA 库存

安装到手机主屏幕，使用方式与普通 App 相同。库存数据只从公司内网服务器实时读取，不会保存在此安装页面。

需要公司 Wi-Fi 或公司 VPN
1. 下载安全证书 2. 打开库存应用

证书文件 SHA-256：EDBE4C8A5CA853F4E378121218EEF23AD5F1058C3AF0E40391814E27BF4A3060

用手机相机扫描此二维码

iPhone / iPad

  1. 下载证书后，打开“设置”中的“已下载描述文件”并安装。
  2. 进入“设置 → 通用 → 关于本机 → 证书信任设置”，为 JA Inventory Internal CA 开启完全信任。
  3. 连接公司网络，用 Safari 打开库存应用并登录。
  4. 点击 Safari 分享按钮，选择“添加到主屏幕”。

Android

  1. 下载证书，在“设置 → 安全 → 加密与凭据”中选择“安装 CA 证书”。
  2. 连接公司网络，用 Chrome 打开库存应用并登录。
  3. 点击页面顶部的“安装”，或在 Chrome 菜单中选择“安装应用”。
  4. 确认后，JA 库存图标会出现在手机桌面。
安全证书只是公开信任凭据，不包含服务器私钥。请勿把网站账号密码转发给无关人员；手机遗失后应及时修改网站密码。
